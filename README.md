# Diwali Sales Data Analysis

## Project Overview

This project analyzes Diwali sales data to understand customer purchasing behavior and identify factors influencing sales performance. The analysis was performed using Python libraries such as Pandas, Matplotlib, and Seaborn to clean the data, perform exploratory data analysis (EDA), and visualize business insights.

---

## Objective

The objective of this project is to:

- Analyze customer purchasing behavior during the Diwali festival.
- Identify customer segments contributing the highest sales.
- Understand demographic trends and product preferences.
- Generate insights to support data-driven marketing decisions.

---

## Analysis Performed

- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Customer Demographic Analysis
- Sales Trend Analysis
- Product Category Analysis

---

## Key Insights

- Female customers made more purchases compared to male customers.
- Customers aged **26–35 years** represented one of the largest purchasing groups.
- Married women contributed significantly to total sales.
- Uttar Pradesh, Maharashtra, and Karnataka generated the highest revenue.
- Customers working in IT, Healthcare, and Aviation showed higher purchasing activity.
- Clothing, Food, and Electronics were among the most popular product categories.

## How to Run the Project

1. Clone the repository.

```
git clone https://github.com/your-username/diwali-sales-analysis.git
```

2. Install the required libraries.

```
pip install -r requirements.txt
```

3. Open the Jupyter Notebook.

```
jupyter notebook
```

4. Run **Diwali_Sales_Analysis.ipynb**
